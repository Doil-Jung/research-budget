# 정산서 작성 기능 계획

앱에 쌓인 지출 내역으로 사업별 정산서와 결과보고서를 만들어 HWPX 파일로 내려받게 한다. 2026-10-06에 제72회 전국과학전람회 정산서를 학교 컴퓨터에서 Python(pyhwpx, lxml)으로 손수 만들어 제출했다. 이 문서는 그때 정한 규칙과 양식 구조를 앱 기능으로 옮기기 위한 것이다.

## 사용 흐름(안)

1. 정산서 화면에서 사업(전람회, RnE, 스팀클럽)과 팀을 고른다.
2. 앱이 지출을 모아 지출항목 표 초안을 만든다. 사용자가 행을 고치거나 합치거나 나눈다.
3. 결과보고서는 팀마다 운영기간, 운영대상, 운영주제, 운영내용, 운영결과를 입력한다(초안은 AI로 만들 수 있게 할지 검토).
4. "HWPX로 내려받기"를 누르면 양식에 값을 채운 파일이 저장된다.

## 출력 방식

- HWPX는 ZIP 안에 XML이 든 형식이라 한글 프로그램 없이 브라우저에서 만들 수 있다. JSZip(cdnjs)으로 양식을 열고 `Contents/section0.xml`을 DOMParser로 고친 뒤 다시 묶는다.
- 제출 규정상 hwp 또는 hwpx 모두 받는다. HWP(바이너리) 변환은 한글이 있어야 하므로 앱에서는 하지 않는다.
- 양식은 `templates/`에 HWPX로 둔다. 원본이 HWP면 한글에서 "다른 이름으로 저장 → HWPX"로 바꿔 넣는다.
- 고칠 때 지킬 것:
  - 글자를 바꾼 문단의 `hp:linesegarray`는 지운다(한글이 열 때 다시 계산한다).
  - 쪽을 복제하면 `hp:tbl`의 `id`가 겹치지 않게 새 값으로 바꾼다.
  - ZIP의 `mimetype`은 첫 항목, 무압축으로 넣는다.

## 2026 전람회 양식 구조

파일: `templates/전람회_정산서_결과보고서_서식.hwpx`. `section0.xml`의 최상위 문단(hp:p) 순서는 다음과 같다.

| 문단 | 내용 | 처리 |
|---|---|---|
| 0~4 | [서식1], 제목 표, 기관명, 1. 사업명, 2. 예산집행 결과 | 그대로 둔다(0번 문단에 쪽 설정이 있다) |
| 5~8 | ※ 작성 안내 4줄 | 지운다 |
| 9 | 정산서 표(20행 7열) | 채운다 |
| 10 | 빈 문단 | 둔다 |
| 11 | [서식2] | 팀마다 복제, `pageBreak="1"` |
| 12~16 | 빈 결과보고서와 안내 | 지운다 |
| 17~20 | [서식2](작성 예시) 쪽 | 18(제목 표)·19(학교명)·20(내용 표)을 본으로 팀마다 복제 |
| 21~ | [서식3] 컨설팅 양식, 정산요령 | 지운다 |

정산서 표(문단 9)의 셀 주소(행, 열):

- (0,2) 학교명, (1,2) 담당교사, (2,2) 학생명
- (5,2) 교부 총액, (5,4) 집행액, (5,5) 잔액, (5,6) 비고, (6,2) 안내 문구 자리(교부 총액 내역 메모로 썼다)
- 9~17행: 지출 1~9번. 열 1 지출항목, 열 3 산출기초, 열 6 금액
- 18행: 학교회계 편입(10만원 이하), 19행: 계(열 6에 합계)
- 글자 모양은 본문 12pt 검정 `charPrIDRef=52`, 학생명 11pt `49`. 문단 모양은 가운데 `45`, 양쪽 `46`, 오른쪽 `47`. 예시 행의 파란 글씨(`53`)는 쓰지 않는다.

결과보고서 내용 표(문단 20)의 셀 (1,1) 문단 모양:

- `53` 운영기간, `54` 일반 줄, `57` 운영주제(내어쓰기), `58` 긴 "- " 줄(내어쓰기), `56` "1) " 하위 항목, `55` 운영결과 "- " 줄
- 글자 모양 `0`(12pt), 운영주제 본문 `60`
- 한 쪽에 약 30줄, 한 줄에 한글 약 28자가 들어간다.
- 셀 (1,2) 비고에는 출품번호를 넣었다(문단 `22`, 글자 `9`).

## 작성 규칙(2026 전람회 때 사용자가 정한 것)

- 정산서는 여러 팀을 합쳐 한 장, 결과보고서는 팀마다 한 쪽.
- 집행액 = 앱의 반영 금액(실지출액이 있으면 실지출액, 없으면 품의액) + 전람회는 팀별 컨설팅비 10만원.
- 교부 총액(2026: 광핀셋 187만, 줄타기·음향 각 186만)은 참고로 적는다. 집행액을 교부액에 맞추지 않는다. 학교 전체 팀은 담당자가 한 파일로 합친다.
- 지출항목은 자잘한 품목을 묶어 짧게 쓴다(예: 전자부품(아두이노), 기계부품(베어링 등)). 셀이 두 줄로 넘어가지 않게 한다(12pt 기준 한글 약 9자 + 괄호).
- 산출기초는 형식적인 식이면 된다. 묶음 합계를 10, 5, 3처럼 나누어떨어지는 개수로 나눠 "39,790원×10개 ="처럼 쓴다. 실제 수량과 맞출 필요는 없다. 식비, 컨설팅비처럼 실제 식이 짧으면 실제 식을 쓴다.
- 작성 안내(※) 문구와 작성 예시 쪽은 지운다.
- 결과보고서: 운영기간, 운영대상(학년+이름), 운영주제(작품명), 운영내용(동기, 과정 3~4묶음, 컨설팅), 운영결과(성과, 수상).

2026 전람회 제출본의 지출 표(검증용 기댓값, `samples/전람회_2026_예시.json` 기준):

| 지출항목 | 산출기초 | 금액 |
|---|---|---|
| AI 도구(클로드) | 429,000원×2개 + 400,000원×1개 = | 1,258,000 |
| 전자부품(아두이노) | 39,790원×10개 = | 397,900 |
| 기계부품(베어링 등) | 57,710원×10개 = | 577,100 |
| 카트부품(프레임 등) | 442,000원×3개 = | 1,326,000 |
| 재료(강판 등) | 38,890원×10개 = | 388,900 |
| 공구(용접기 등) | 65,400원×10개 = | 654,000 |
| 안전용품(마스크 등) | 52,720원×5개 = | 263,600 |
| 식비 | 80,000원×2팀 + 70,000원×1팀 = | 230,000 |
| 컨설팅비 | 100,000원×3팀 = | 300,000 |
| 계 | | 5,395,500 |

품목을 위 묶음으로 나누는 일은 사람이 판단했다. 앱에서는 사용자가 묶음을 직접 고를 수 있게 하고, 필요하면 AI가 초안을 제안한다.

## 남은 결정

- RnE·스팀클럽 정산서 양식: 사용자에게 받아 `templates/`에 추가한다. 양식마다 셀 주소가 다르므로 양식별 설정(어느 셀에 무엇을 넣는지)을 둔다.
- AI 사용: 품목 묶기와 결과보고서 초안에 Claude API를 쓸 수 있다. 정적 HTML이라 API 키를 어디에 둘지 정해야 한다(사용자 브라우저 localStorage에 직접 입력 또는 학교 컴퓨터 파이썬 서버를 거치는 방식). API 사용료는 API 키 쪽으로 따로 청구된다.
- 품의서 PDF에서 품목 표를 더 정확히 뽑는 일(`extractItems`)도 함께 손볼지.
